# Pinnacle

A two-player pixel-art quiz climb (see README.md). Before any work:

1. Read `WORKLOG.md`: what has been done, standing decisions (e.g. the rope jerk stays strong), and what is open.
2. Use the project skills in `.claude/skills/` instead of re-deriving things:
   `pinnacle-codebase` (where things are), `pinnacle-qa` (ready-made visual and glitch checks),
   `pinnacle-release` (commit checklist), `pinnacle-map-trails` (map routes).
3. After committing, add a short entry to the top of the worklog's Log.

Players only get `main`; work lands on a session branch until it is merged.
